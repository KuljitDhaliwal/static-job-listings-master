# Static Job Listings

A responsive job listings application built as a solution to the Frontend Mentor Static Job Listings challenge.

## Features

- Responsive design
- Filter jobs by role, level, languages, and tools
- Multiple filters
- Remove individual filters
- Clear all filters
- Featured job listings
- Responsive layout

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite

## What I Learned

- React Context API
- Custom React hooks
- State management
- Array methods: `filter()`, `every()`, and `includes()`
- Conditional rendering
- Responsive design
